Use the `debugger` subagent to find and fix the described bug or error.

Bug description or error message: $ARGUMENTS

If $ARGUMENTS is empty — describe the problem you're seeing before running this command.

The debugger will:
1. Ask clarifying questions if the bug is ambiguous (expected vs actual behaviour, error message, reproduction steps)
2. Read all relevant files before suggesting a fix
3. Identify the root cause — not just the symptom
4. Provide the minimal fix with full context
5. Explain how to verify the fix works
