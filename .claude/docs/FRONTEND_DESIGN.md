# Frontend Design Guide

Создание самобытных, production-grade Vue 3 интерфейсов с высоким дизайн-качеством.
Агент: `code-frontend-design` — активируется автоматически при запросах на UI.

---

## Что делает агент

- Выбирает **чёткое эстетическое направление** и исполняет его с точностью
- Избегает generic "AI slop": Inter, фиолетовые градиенты, шаблонные card-компоненты
- Генерирует полные Vue SFC файлы с FSD-размещением
- Добавляет анимации, типографику, атмосферные фоны

---

## Как использовать

```
"Сделай красивую карточку блюда для каталога"
"Построй dashboard для admin-панели с графиками"
"Спроектируй страницу авторизации — dark theme, luxury стиль"
"Нарисуй sidebar с навигацией — editorial, magazine-feel"
```

Агент прочитает существующие компоненты проекта, выберет направление совместимое
с текущей эстетикой, и выдаст готовый Vue 3 + Tailwind CSS v4 код.

---

## Эстетические направления

| Направление | Характер |
|---|---|
| **Refined minimal** | Воздух, геометрия, тонкие линии, чёткая типографика |
| **Editorial** | Крупные заголовки, асимметрия, magazine-layout |
| **Warm organic** | Скруглённые формы, тёплые тона, мягкие тени |
| **Luxury** | Золотые акценты, тонкие шрифты, generous whitespace |
| **Brutalist** | Высокий контраст, намеренная сырость, bold borders |
| **Playful** | Неожиданные цвета, округлые формы, живые анимации |

---

## FSD размещение результата

| Что создаётся | Куда |
|---|---|
| UI-примитив (кнопка, badge, input) | `shared/ui/ComponentName/` |
| Составной блок (секция, sidebar) | `widgets/widget-name/ui/` |
| Форма или модалка с логикой | `features/feature-name/ui/` |
| Страница целиком | `pages/section/PageName.vue` |

---

## Советы для лучшего результата

- **Укажи контекст** — "для admin-панели" vs "для клиентского приложения" даст разный результат
- **Назови аудиторию** — ресторан-менеджер или конечный пользователь
- **Укажи тему** — "dark", "light", или "на твоё усмотрение"
- **Дай референс** — "в стиле Linear", "как Stripe Dashboard", "минималистично как Apple"
- Если всё устраивает — "на твоё усмотрение": агент примет решение и обоснует его
